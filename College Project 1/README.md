# Team SiteSavvy – Enhanced (Merged + No Local Images)

## What's inside
- `index.html` – Single-page website (Home, About, Services, Portfolio, Team, Contact)
- `assets/main.css` – Single shared stylesheet
- `assets/main.js` – Small menu behavior
- `assets/docs/` – PDF resumes/CVs

## Key upgrades
- Fewer files (easy to host / submit)
- Local logo + social images removed
- Logo + illustrations converted into SVG code
- Team pictures replaced with online placeholder avatars (DiceBear)
- Modern color theme: Midnight + Cyan + Violet

## How to run
Just open `index.html` in your browser.

## Notes
If you want the contact form to actually send messages, connect it to Google Forms or EmailJS.
